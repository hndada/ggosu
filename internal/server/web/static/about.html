gosu 소개

좋아하는 곡의 채보를 찾아 건반으로 플레이하는 리듬 게임이에요. 웹에서 바로 시작하거나 PC에 내려받아 즐길 수 있어요.

웹에서 플레이PC 다운로드

여러 채보를 한곳에서

곡을 고르고, 난이도를 선택하고, 나만의 기록을 남기세요.

  • osu!mania (.osu)
  • O2Jam (.ojn)
  • BMS (.bms, .bme, .bml)
  • StepMania (.sm)
  • gosu (.ggc)

일부 원본 기능은 지원 범위가 달라요.

처음 시작하기

웹플레이는 별도 설치 없이 실행할 수 있어요. 첫 시작에는 게임을 불러오는 시간이 필요해요.

  1. 웹플레이에서 곡과 채보를 고르세요.
  2. 일반 플레이 또는 Auto를 선택하고 플레이를 누르세요.
  3. 게임이 준비되면 게임 안의 시작 버튼을 누르세요. 레인에 표시된 키를 사용해요.

PC 설치

  1. Windows용 gosu를 내려받으세요.
  2. ZIP 파일의 압축을 풀고 gosu.exe를 실행하세요.
  3. 추가 곡은 함께 들어 있는 songs 폴더에 넣으세요.

현재 제공하는 개발 빌드에는 곡 선택 앱, 플레이 앱, 데모 곡이 포함돼요.

채보 편집

기존 채보를 열어 노트·타이밍을 수정하고, 파형을 보며 구간을 들어볼 수 있어요. 저장하면 원본을 유지한 채 새 gosu 채보 사본을 만들어요.

편집할 채보 선택

새 곡으로 채보 만들기와 원본 포맷 내보내기는 준비 중이에요.

기록·리플레이

홈의 최근 플레이는 이 브라우저에 저장된 기록이에요. 다른 기기에서 보려면 기록·리플레이를 내보내고 가져오세요. 브라우저 데이터를 지우기 전에 기록을 백업하세요.

기록·리플레이 관리

유저 페이지

계정과 공개 유저 페이지는 준비 중이에요. 제작한 채보와 플레이 활동은 같은 유저 페이지에서 볼 수 있도록 만들 예정이에요.

플레이 이야기를 나누고, 채보를 소개하고, 궁금한 점을 물어볼 공간을 준비하고 있어요.
