# 단축키

[osu! 기본 단축키](https://osu.ppy.sh/wiki/en/Client/Keyboard_shortcuts)의 지원 기능을 gosu에 연결한다.

| 화면 | 키 | 동작 |
| --- | --- | --- |
| 메뉴 | Ctrl+O | 설정 열기·닫기 (기존 F10 유지) |
| 타이틀 | P / M / E / O / Q | 싱글 / 멀티 / 편집 / 설정 / 종료 확인 |
| 곡 선택 | F1 / F2 / Shift+F2 / F3 / F5 | 모드 / 랜덤 / 랜덤 되돌리기 / 채보 메뉴 / 목록 다시 읽기 |
| 곡 선택 | Enter / Ctrl+Enter | 플레이 / Auto 플레이 |
| 곡 선택 | Ctrl+A | Auto 전환. 검색어가 있으면 검색어 전체 선택 |
| 곡 선택·플레이 | Ctrl+F3 / Ctrl+F4, Ctrl+플러스 / Ctrl+마이너스 | 표시 속도 증가 / 감소 |
| 플레이 | F3 / F4 | 표시 속도 증가 / 감소 (플레이 중에도 사용 가능) |
| 곡 선택·플레이 | PageUp / PageDown, Alt+PageUp / PageDown | 표시 속도 조절 / 미세 조절 |
| 플레이 | Shift+F4 | SUDDEN+ 켜기·끄기 |
| 플레이 | Ctrl+R 또는 백틱 0.2초 누르기 | 재시도. 멀티에서는 사용하지 않음 |
| 플레이 | Shift+Tab | HUD 숨기기·표시. 일시정지 메뉴는 유지 |
| Auto·리플레이 | H | HUD 숨기기·표시 |
| 일시정지 | Tab 누르고 있기 | 일시정지 화면을 잠시 숨겨 필드 보기 |
| F1 모드 창 | X / F / G / V | Random / Fade In → Hidden → OFF / Flashlight / Auto 전환 |
| 편집 | C 또는 Space / X / Z / V / F5 | 재생·정지 / 처음부터 재생 / 첫 노트 / 마지막 노트 / 테스트 |
| 메뉴·플레이 | Alt+방향키 | 볼륨 조절 |
| 메뉴·플레이 | Alt+Enter / F12 | 전체화면 / 스크린샷 |
| 방 채팅 | F8 | 채팅 열기·닫기 |

문자 입력·IME 조합 중에는 편집 동작을 우선한다. 토글 키를 누른 채 유지해도 반복 전환하지 않는다.
gosu의 키 수·곡 목록·편집 도구에 쓰는 기존 키도 유지한다. osu!의 다른 게임 모드, Cinema, 서버 스크린샷 공유처럼 gosu에 없는 기능의 키는 추가하지 않는다.
