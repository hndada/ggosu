# 곡 선택창

## 메들리

타이틀의 **메들리 모드**에서 키 수와 계산 Lv 범위를 고르고, 제목·아티스트·난이도로 검색해 원하는 채보의 행을 눌러 선택한다. 최대 3곡이며, 선택한 행을 다시 누르거나 왼쪽 구성 목록의 곡을 누르면 뺀다. 같은 곡의 다른 난이도를 선택하면 기존 난이도를 교체한다. O2Jam은 같은 폴더 안에서도 `.ojn` 파일마다 다른 곡으로 구분한다. 싱글 플레이와 같은 레벨·곡명 행, 선택 강조와 하단 단축키 바를 사용한다.

**랜덤 뽑기 [F2]**는 현재 키 수와 Lv 범위에서 최대 3곡을 뽑아 선택 전체를 바꾼다. 검색어는 직접 고르는 목록에만 적용한다. 키 수나 Lv 범위를 바꾸면 조건 밖의 선택은 빠지고, 검색만 바꾸면 선택은 유지된다. 후보 목록은 계산 Lv가 있고 첫 노트부터 마지막 노트까지 60초 이상인 채보를 표시하며, 100채보씩 이전·다음으로 탐색할 수 있다.

방향키로 목록을 이동하고 **Space**로 담기·빼기를 전환한다. **Enter**로 시작하고 **Ctrl+Enter**나 하단 **Auto**로 Auto를 실행한다. **Ctrl+Backspace**로 선택을 비운다. Tab은 입력·목록·하단 조작 사이를 이동한다. 선택한 곡들의 재생 순서와 구간은 후렴의 노트 밀도에 따라 자동으로 구성된다. 싱글 전용이며 기록은 저장하지 않는다.

키 바인딩·스크롤·기준 노출·변속·볼륨·배경 설정은 [환경 설정](preferences.md)을 참고한다.
노트 분포·최고 기록 비교·Mirror/Random·Time Rate는 [모드](play-options.md)을 참고한다.
이 문서의 14,000점·5,000점 검증 수치는 이전 규칙의 결과다. 현재 점수와 기록 구분은 [110만점 규칙](score.md)을 따른다.

`App.Catalog` → `internal/chart.Scan`으로 실제 `songs/`를 검색한다.
현재 디렉터리에 없으면 실행 파일 옆의 songs를 읽는다. OJN·SM의 여러 난이도도 각각 표시한다.
잘못된 채보는 오류를 알리고 제외한다. 새 파일을 넣으면 '곡 목록 새로 읽기'를 누른다.

## 화면 구성과 조작

스크롤 바는 모든 화면·패널·입력 영역에서 표시하지 않는다. 긴 목록·기록·설정·채팅은 휠·터치·키보드로 탐색한다.
곡 정보는 왼쪽 상단의 280~360px 영역, 검색과 곡 목록은 그 옆 중앙 영역에 배치한다. 필터를 포함한 명령 버튼은 화면 아래에 둔다.
방 채팅을 펼치면 오른쪽에 채팅 280px와 간격 16px를 확보해 목록과 나란히 표시한다. 채팅을 접으면 목록이 그 공간을 다시 사용한다.
곡 Info는 배경 썸네일, 제목·아티스트·채보 제작자, 원본 레벨·난이도·키 수, 같은 곡/키 수의 채보 개수와 로컬 클리어 상태를 구분해 표시한다.
계산 난이도가 있는 채보는 곡 Info와 목록의 계산값 바로 옆에 원본 레벨을 작은 글씨의 괄호로 표시한다. 원본 값의 소수점·문자는 그대로 보존한다. 계산값이 없을 때는 원본 레벨만 표시한다.
곡 Info에는 편집 버튼을 두지 않는다. 목록의 채보 또는 선택한 곡 Info를 우클릭하면 추가 메뉴가 열리며, '채보 편집'으로 해당 채보를 연다. 메뉴 밖 클릭·Esc·스크롤로 메뉴를 닫는다.
`169 Notes (LN 1.8%)` / `200BPM`(변속이면 범위) / `0:38`(채보 길이) 세 줄과 작은 노트 밀도 그래프를 함께 표시한다. 평균·최고 구간 NPS는 그래프 툴팁에 있다. 수치는 원곡 1배속 기준이며 Fake·지뢰는 재생 노트 시작 수에서 제외한다. LN 비율은 LN/roll 시작 수를 전체 재생 노트 시작 수로 나눈 값이다.
평균 NPS는 재생 노트 시작 수/채보 길이, 최고 구간 NPS는 분석 구간 평균의 최댓값이다. 작은 그래프는 구간을 최대 40칸으로 묶고 각 묶음의 최고 구간 밀도를 보존한다. 이는 사람의 난이도나 별점이 아니다. 분석을 아직 읽지 못한 값은 '—'로 표시한다.
'정렬·필터 [F4]' 창에서 키 수·레벨·길이 조건을 한 창으로 조작한다. 조건은 즉시 적용하며, 적용 중에는 버튼 이름이 '필터 적용'으로 바뀐다.
곡 정보 아래의 '랭킹'은 로컬·라이벌·글로벌 중 고른 랭킹을 표시한다. 로컬은 선택한 채보의 일반 플레이 점수이며, 정렬 버튼을 누를 때마다 점수순과 날짜순이 바뀐다. 라이벌·글로벌은 랭킹 서버가 아직 없어 기록을 표시하지 않는다.
목록은 점수만 보이고, 마우스를 올리면 정확도·콤보·날짜와 기본값이 아닌 조건(배속·Pitch Off·Mods·보정)이 나온다. 점수를 누르면 결과 화면이 열리고, 그 화면에서 리플레이를 재생한다. 0점으로 끝난 플레이는 기록하지 않고 결과 화면 없이 곡 선택으로 돌아간다.
데스크톱은 실행 파일 옆 `data/records/`, 웹은 현재 브라우저에 저장된 기록을 읽는다.

곡·채보를 선택하면 음악 프리뷰를 자동으로 준비한다. osu!의 `PreviewTime`, StepMania의 `SAMPLESTART`가 있으면
그 위치에서 최대 15초씩 반복하며, 지정이 없거나 오디오 범위를 벗어나면 처음부터 재생한다.
짧은 곡은 남은 오디오 길이만 반복한다. BMS·O2Jam은 BGM과 노트 키음을 함께 재생하고, `.ggc` 사본도 원본 포맷 정보를 따른다.
프리뷰는 선택창의 Time Rate(0.5–2.0배)와 Pitch를 따른다. Pitch On은 속도와 음높이가 함께 바뀌고, Off는 원래 음높이를 유지한다.
재생 중 배속을 바꾸면 현재 원곡 위치를 유지하며 새 배속을 즉시 적용한다. 시작 위치·구간·키음 시각은 원곡 시간 기준이다.
같은 음원 파일과 오디오 배치를 참조하는 채보로 바꾸면 현재 프리뷰·재생 위치·반복을 유지한다. 채보 ID나 프리뷰 시작 지점이 달라도 음원이 같으면 다시 읽거나 재생하지 않는다.
곡 제목이 같아도 실제 참조 파일이나 BMS·O2Jam 키음 배치가 다르면 새 프리뷰로 전환한다.
프리뷰는 선택한 곡을 자동으로 재생하고 저장한 음악 볼륨을 적용한다. 별도의 켜기·끄기 버튼이나 정상 재생 상태 표시는 두지 않는다.
브라우저가 자동 재생을 막으면 첫 클릭·키 입력으로 시작한다. 오디오 읽기·재생 실패만 알린다.
빠른 목록 이동은 200ms 뒤 마지막 선택만 읽으며, 이전 선택의 로딩은 취소한다. 현재 소리는 음원 비교가 끝날 때까지 유지하고, 다른 음원이면 전환한다.
플레이·리플레이·Edit 진입, 결과 화면, 빈 검색 결과, 숨겨진 탭에서는 정지한다. 곡 선택 화면으로 돌아오면 다시 준비한다.
파일이 없거나 디코딩에 실패하면 프리뷰 상태에 파일명·샘플 번호·원인을 표시한다. 여러 실패의 전체 내용은 툴팁에서 확인한다. F5로 곡 목록을 다시 읽으면 오디오도 재시도한다.
O2Jam 프리뷰와 게임은 M30(무암호화/nami/0412), OJM, 암호화 OMC를 지원한다. 뱅크의 빈 샘플 슬롯은 소리가 없는 참조로 처리한다.
M30의 샘플 수가 실제보다 커도 마지막 완전한 레코드까지 읽는다. 뱅크 끝이 실제로 잘린 경우 앞쪽의 온전한 샘플은 재생하고, 잘린 부분의 요청은 오류로 표시한다.

프리뷰 검증: 전체 Go 테스트·`go vet ./...`, 프런트엔드 테스트 31개와 Wails 빌드를 통과했다.
브라우저의 실제 `AudioContext`와 `AnalyserNode`로 데모 4개 포맷의 출력, 음소거·정지 후 0 출력,
osu! 프리뷰 구간 반복을 확인했다. 측정값은 [검증 기록](../../artifacts/10-songselect/preview-audio.json)에 보존했다.
새 Wails 실행 파일에서 프리뷰 상태를 확인했고, 브라우저에서 켜기·끄기와 Edit 왕복을 확인했다.
물리 스피커 청취·출력 지연 측정은 포함하지 않는다.

배속 연동 변경 후 프런트엔드 테스트 37개와 Wails 빌드를 통과했다. 실제 브라우저에서 Time Rate 2배 입력의 프리뷰 반영,
0.5배·2배 음높이 변경, 현재 곡 위치 유지, 2배 반복 주기를 확인했다. [배속 검증 기록](../../artifacts/10-songselect/preview-playback.json).

Pitch 옵션 추가 후 전체 Go 테스트·vet, 프런트엔드 테스트 45개, Wails·WebAssembly 빌드를 통과했다.
이전 0.25–4배 범위의 검증에서 실제 프리뷰의 Off는 0.25·0.5·2·4배 모두 원래 주파수를 유지했다. 현재 제공 범위는 0.5–2.0배다. 2배·Off 네이티브/웹 Auto와 웹 리플레이는
14 KOOL·MISS 0·1,100,000점으로 일치했고, 기록의 Off 옵션도 복원했다. [Pitch 검증 기록](../../artifacts/10-songselect/pitch-audio.json).

설계 근거와 레퍼런스는 [곡 선택 화면 설계](../design/songselect-design.md)를 참고한다. 1단계(화면 틀·검색·필터·키 수 탭·보기 전환·키 안내)를 구현했다.
Wails와 브라우저가 같은 화면을 쓴다. 레이아웃은 배치 전용 CSS(`scenes/layout.css`)만 사용한다.

- 위: 검색창, 정렬, 보기 전환, 필터 줄(레벨·길이 구간·플레이 기록), 키 수 탭. 왼쪽: 선택한 채보 정보·모드·Mods·Time Rate·노트 분포·기록. 오른쪽: 곡 목록. 아래: 키 안내 줄.
- **키 수는 여러 개를 함께 고를 수 있다.** 목록 위 키 수 버튼과 필터 창 체크박스가 같은 선택을 보여주며, 누를 때마다 그 키 수를 더하거나 뺀다. 마지막 하나는 끌 수 없다. F7/Shift+F7은 키 수 하나씩 차례로 고른다. 괄호 숫자는 현재 검색·필터에 맞는 채보 수다. 마지막 선택과 키 수 조합별 마지막 채보를 기억한다.
- **곡 묶음 / 채보 목록**: 곡 묶음은 선택한 곡만 펼치고 채보가 6개를 넘으면 선택 주변만 보인다. 채보 1개인 곡은 한 줄이다. 채보 목록은 레벨 정렬에서 `Lv 12` 구분선을 넣는다.
  정렬을 바꾸면 기본 보기는 정렬 기준을 따른다(제목 = 곡 묶음, 레벨 = 채보 목록). F6으로 바꾼 보기는 그 정렬에서 기억한다.
- 검색어가 바뀌어 선택한 채보가 결과에서 빠지면 첫 결과를 선택한다. 그래서 입력 직후 Enter로 첫 결과를 플레이할 수 있다.

목록을 읽는 중이거나 플레이 중, 설정·오프셋을 저장하지 않은 동안에는 선택 이동을 막는다.

## 검색·필터·정렬

### 달성 표시와 최근 플레이

- 각 채보 행은 왼쪽부터 점수 램프, 풀콤보·퍼펙트 램프, 레벨, 제목 순으로 표시한다. 레벨은 `Lv` 접두어 없이 큰 두 자리 정수로 표시한다(`4` → `04`, `16.5` → `16`). 소수점 이하는 버리고 원본 채보·정렬·필터의 레벨 값은 유지한다. 레벨 정보가 없으면 `--`로 표시한다. 램프는 IIDX 선택 목록을 참고한 발광 막대 두 개를 빈틈 없이 붙인다. 분할선이나 테두리 장식 없이 색과 빛 번짐으로 표현하며 램프·레벨은 제목 길이와 관계없이 왼쪽 같은 위치에 고정한다.
- 표시 폭을 넘는 긴 제목은 한 줄 안에서 초당 24px로 천천히 왕복한다. 시작과 끝에서 1.6초씩 멈추고 레벨·램프·점수는 고정한다. 창 크기와 채팅 패널 너비에 맞춰 다시 계산하며, 짧은 제목은 움직이지 않는다. 마우스를 올리면 전체 제목을 볼 수 있다. 운영체제의 동작 줄이기 설정에서는 이동을 끈다.
- 점수 램프는 최고 점수에 따라 80만 미만(회색), 80만 이상(파랑), 90만 이상(초록), 100만 이상(앰버), 105만 이상(보라), 110만(흰색)으로 발광한다. 완주 기록이 없으면 꺼져 있으며, 0점 완주는 회색 램프를 켠다. 최고 점수도 함께 표시한다.
- 100만점 이상 점수 램프는 밝기가 서서히 맥동한다. 두 번째 램프는 클리어 램프다. 완주·1단 완주·2단 완주·3단 완주·풀콤보·퍼펙트가 같은 자리를 쓰며 높은 달성을 우선한다. 체력은 0%가 되면 3→2→1단으로 자동으로 내려가므로, 곡이 끝났을 때 0%보다 남아 있는 단계가 그 플레이의 단계 완주다. 체력을 끄거나 1단까지 0%가 된 채 끝나면 단계 없는 완주다. 단계 완주는 현재 체력 값으로 기록된 플레이만 인정한다. 글자 없이 막대로 표시한다. 완주는 발광 없는 회색, 1·2·3단은 초록·파랑·보라, 풀콤보는 은백색, 퍼펙트는 금색이다. 단계가 높을수록 막대 가운데의 밝은 심지와 빛 번짐이 커지며 퍼펙트가 가장 밝다. 완주 기록이 없으면 꺼져 있다. 점멸하지 않는다. 동작 줄이기 설정에서는 맥동 없이 기본 색으로 켠다.
- 풀콤보는 MISS 없이 전체 판정을 콤보로 연결한 기록이며 GOOD도 포함한다. 퍼펙트는 모든 판정이 COOL 이상(KOOL·COOL)인 기록이다. 판정이 없는 채보에는 달성을 부여하지 않는다. 각 램프에 마우스를 올리면 구간·달성을 확인할 수 있다.
- 곡 목록 최고 점수는 현재 110만점 규칙의 일반 플레이·완주·1배속·도중 배속 변경 없음 기준으로 기본·Mirror·Random 기록 중 가장 높은 점수를 표시한다. 기존 저장 기록에도 같은 기준을 적용한다. 연습·미완주·이전 점수 규칙·검증 불가 기록은 최고 점수를 올리지 않는다.
- 완주·풀콤보·퍼펙트 달성은 위 조건에 배치 변경 없음 기준을 추가한다. 이후의 낮은 점수나 미완주가 이전 달성을 지우지 않는다.
- 곡 묶음 행의 `완주 n/m`은 현재 검색·필터에 포함된 채보 중 위 조건으로 완주한 수다. 선택한 곡을 펼치면 개별 채보의 달성과 점수를 볼 수 있다.
- 목록 위의 **최근 플레이**는 현재 입력 판정 규칙에 맞는 저장된 일반 플레이를 마지막 플레이순으로 보여준다. 연습·미완주·이전 점수 규칙도 포함하며 Auto·리플레이는 제외한다. 기존 검색·키 수·범위·기록 필터를 함께 적용한다.
- 최근 플레이는 최신순을 고정하고 일반 정렬을 잠시 비활성화한다. 전체 곡으로 돌아오면 이전 정렬을 사용한다. 곡 묶음과 채보 목록 보기 모두 지원하며 최근 플레이의 보기 선택은 별도로 기억한다.
- 채보 내용 해시로 기록을 연결하므로 이름·파일 경로가 달라도 같은 내용이면 같은 달성을 표시하고, 내용이 바뀌면 별도 채보로 취급한다. 기록 읽기 실패는 미플레이로 표시하지 않고 오류 상태와 F5 재시도를 안내한다.
- 목록 로딩·플레이 종료·브라우저 기록 가져오기 후 갱신한다. 데스크톱은 기록을 한 번 읽어 채보별 요약만 전달하고, 브라우저는 해당 origin의 저장된 기록을 같은 조건으로 집계한다.

검색 조건 변경은 메모리의 목록만 처리한다. 목록 갱신·채보 선택 후 기록 조회·플레이 검증은 기존 파일 읽기 경로를 사용한다.

- 검색창: 제목·아티스트·제작자·난이도 이름. 공백으로 나눈 검색어를 모두 포함해야 한다. NFKC 정규화와 소문자 변환을 적용한다. 원본 레벨은 검색하지 않고 레벨 필터로 거른다.
- 필터 창: 키 수 체크박스와 레벨·길이 **범위 창**. 서로 다른 조건은 모두 만족해야 한다.
- **범위 창**: 숫자를 입력하지 않고 분포 막대 위에서 창을 끌어 고른다(`scenes/songselect/range.js`, 계산은 `songlist/range.js`).
  - 빈 곳을 끌면 새 창, 창 가운데를 끌면 이동, 양쪽 끝을 끌면 폭 조절, 두 번 클릭하면 전체로 되돌린다. 창에 포커스를 두고 ←→ 이동, Shift+←→ 폭 조절.
  - 레벨은 **Lv 1~40 고정** 칸이다. 1 미만은 첫 칸, 40 초과는 마지막 칸(`40+`)에 들어간다. 소수 레벨(12.5)은 정수 칸(12)에 속한다. 숫자로 읽을 수 없는 레벨은 레벨 창을 쓰면 제외된다.
  - 길이는 **0:20~8:00 고정** 10초 칸이다. 20초 미만은 첫 칸, 8분 이상은 마지막 칸에 들어간다.
  - 막대 높이는 고른 키 수에서 자기 조건을 뺀 나머지 조건을 모두 통과한 채보 수다. 칸은 고정이라 입력 중에도 움직이지 않는다.
  - 아무 범위도 고르지 않은 상태에서는 막대가 회색이고 창이 보이지 않는다.
  - 이전의 길이 구간 버튼과 구간 겹침 설정은 범위 창으로 대체했다.
- 플레이 기록: 현재 판정 규칙의 일반(live) 플레이 기록이 하나라도 있으면 '플레이함'이다. Auto·리플레이 재생만 있는 채보는 미플레이다. 목록 행의 `✓`/`·`도 같은 기준이다.
  `App.Played`가 기록 파일의 채보 digest 목록을 돌려주고, 목록의 각 채보는 `hash`(채보 digest)를 갖는다. 웹은 브라우저 저장소의 기록으로 같은 목록을 만든다.
- 클리어 램프 필터: 미플레이·플레이함·완주·1단 완주·2단 완주·3단 완주·풀콤보·퍼펙트 버튼을 여러 개 켤 수 있고, 켠 램프 중 하나에 해당하면 포함한다. 아무것도 켜지 않으면 거르지 않는다. 버튼 옆 숫자는 램프 외 조건을 통과한 채보 수다. 기록을 읽지 못하면 램프 필터를 쓸 때 결과를 비우고 F5 재시도를 안내한다.
- 정렬: 제목·레벨(원본 레벨과 난이도 이름)·클리어 램프 세 가지다. 정렬 창의 오름차순·내림차순 버튼이나 Shift+F4로 방향을 바꾸며 기본은 오름차순이다. 방향은 기준 값에만 적용하고, 같은 값 안의 순서와 누락값을 끝에 두는 규칙은 그대로다. 최근 플레이 목록에서는 방향을 바꿀 수 없다. 클리어 램프 오름차순은 미플레이 → 플레이함 → 완주 → 1단 → 2단 → 3단 완주 → 풀콤보 → 퍼펙트 순이고 채보 목록 보기에서 램프마다 구분선을 넣는다. 램프 기준은 위 달성 표시와 같다. 같은 값이면 제목 → 숫자 레벨 → 파일 경로 → 원본 인덱스 순이다. 한 곡의 채보는 쉬운 것부터 나온다.
- 랜덤: 현재 키 수·검색·필터에 맞는 채보에서 같은 확률로 하나를 고른다. 자동으로 플레이하지 않는다.

| 값 | 기준 |
|---|---|
| BPM | 원본 채보 전체 타이밍의 양수 BPM 최솟값·최댓값. 스크롤 배율은 제외한다. 검색 범위와 겹치면 포함하며, 정렬은 최솟값 → 최댓값 순이다. |
| 채보 길이 | 첫 노트 시작부터 마지막 노트 끝까지의 초. 음수 시작 시각과 롱노트 끝을 포함한다. 오디오 길이나 종료 대기 시간과는 다르다. |
| 날짜 | 채보 원본 파일의 수정 시각. 날짜 필터는 이 기기의 현지 날짜로 양쪽 경계를 포함하며, 정렬은 실제 수정 시각을 사용한다. 공개일·추가일은 아니다. |
| 원본 레벨 | 포맷별 레벨 표기를 유지한다. 숫자 범위 필터는 숫자로 읽을 수 있는 레벨만 대상으로 한다. 정렬은 숫자가 포함된 문자열을 자연 정렬하고, 같으면 난이도 이름으로 비교한다. 게임 간 공통 체감 난이도를 뜻하지 않는다. |
| 누락값 | 해당 조건의 필터에서는 제외하고, 조건이 없으면 포함한다. 정렬에서는 양쪽 방향 모두 마지막에 둔다. 하나의 탭으로 길이가 0초인 채보는 값이 존재한다. |

범위 창은 두 번 클릭하면 전체로 돌아간다. 검색어는 필터와 따로 유지한다.
컬렉션 및 검색 조건의 재실행 후 저장은 아직 제공하지 않는다.

검증 명령: `go test ./...`, `go vet ./...`, `node --test` (`scripts/check.ps1`이 UI 폴더의 `*.test.js`를 모두 실행).
`songlist/list.test.js`는 길이 구간 겹침, 플레이 기록 필터, 레벨 텍스트 제외, 키 수별 개수, 곡 묶음·채보 목록 배치와 구분선, 긴 곡의 표시 범위, 이동 규칙을 테스트한다.
웹 서버(`cmd/web`)에서 키 수 탭 전환, 입력 즉시 검색과 탭 개수 갱신, Esc 두 번으로 검색 전 선택 복귀, F4 레벨 정렬의 구분선, F2 랜덤, F6 보기 전환, Ctrl+F 상세 조건 창을 확인했다.
Wails 빌드(`build/bin/gosu.exe`)에서 F10 설정 창에 선택 채보의 키 수 설정이 열리는 것을 확인했다.

## 플레이 흐름

플레이는 목록의 파일·난이도를 재검증한 뒤 `game.exe`에서 실제 건반 게임을 실행한다.
첫 Draw에서 준비 완료를 알린다. 게임 종료 후 다시 선택할 수 있으며 선택창 종료 시 게임도 회수한다.
중복 실행을 막는다. 기존과 같이 배치 전용 CSS 규칙을 따른다.
게임 플레이는 중앙 레인·좌우 HUD·상태 안내를 갖춘 `view`로 표시한다.
구성과 레퍼런스 비교·성능 검증은 [플레이 Scene 안내](../dev/scene.md)를 참고한다.

배포에는 `gosu.exe`, `game.exe`, `songs/`를 같은 디렉터리에 둔다.

```powershell
$env:GOMODCACHE = Join-Path (Get-Location) '.cache/mod'
$env:GOCACHE = Join-Path (Get-Location) '.cache/build'
pwsh -NoProfile -File scripts/desktop.ps1 build
Copy-Item -LiteralPath songs -Destination build/bin -Recurse -Force
```

Wails postBuildHook은 게임 실행 파일도 빌드한다. 미리듣기·스킨 설정·압축 묶음 가져오기는 아직 제공하지 않는다.
일반/Auto 모드를 선택할 수 있다. 종료 후 결과 화면과 다시 하기·리플레이 보기·곡 선택으로 돌아가기를 제공한다.
결과와 입력은 실행 파일 옆 `data/records/`에 저장하며, 채보별 기록 목록에서 리플레이를 재생한다.
Auto·배속·중도 종료·리플레이 결과는 일반 플레이 최고 기록과 구분한다.
최고 기록은 일반 플레이·1배속 완주·배속 변경 없음 조건에서 배치 종류와 실제 매핑이 같은 기록만 비교한다.
기록은 채보 내용 해시·판정 규칙이 같은 것만 표시한다. 미완주 리플레이는 원래 종료 시각까지만 재생한다.
결과와 리플레이를 임시 파일에 모두 쓴 뒤 기록 파일로 옮겨 불완전한 저장을 목록에 노출하지 않는다.
CLI에서도 `-result`, `-replay-record`, `-record`, `-replay`를 사용할 수 있다. 원본 레벨은 게임 간 비교 지표가 아니다.

## 타이밍 보정

Wails의 타이밍 보정 화면에서 전체·선택한 채보 오프셋을 정수 ms로 입력하고 저장한다.
각 값의 범위는 -1000~1000 ms이고, 적용값은 두 값의 합이다.
양수는 노트 표시·스크롤 변속·판정 시각을 음악보다 늦게, 음수는 빠르게 이동한다.
BGM과 배경·스토리보드의 시각은 유지하며, 키음은 기존처럼 입력·판정에 따라 재생한다.
원본 채보 파일과 내용 해시는 변경하지 않는다.

설정은 실행 파일 옆 `data/settings.json`에 저장한다. 채보별 값은 원본 채보 내용 해시로 구분한다.
전체 값 초기화는 전체 값만, 채보 값 초기화는 선택한 채보 값만 0으로 저장한다.
다른 채보의 값은 유지한다. 편집 중인 값을 저장하기 전에는 새 일반/Auto 플레이를 시작하지 않는다.
플레이 도중에는 설정 저장을 막는다. 설정 읽기·저장이 실패하면 오류를 표시한다.

CLI에서는 `-offset 40 -chart-offset -15`처럼 지정한다. 이 예의 적용값은 +25 ms다.
보정값은 레인 리플레이의 `offsets`에 저장하며 리플레이 재생은 현재 설정보다 저장된 값을 우선한다.
기존 보정값 없는 기록은 0/0으로 읽는다. 네이티브 기록을 웹에 가져와도 저장된 보정값으로 재생한다.
웹에서는 Wails 보정 설정 화면을 제공하지 않는다.

플레이 화면에는 점수와 오차 미터를 표시한다. 음수 오차는 Early, 양수는 Late다.
미터는 최근 2초간 성공한 노트 시작 입력을 표시하고, 최근 최대 64개 입력의 평균을 보여준다.
자동 롱노트 끝 판정·지뢰 회피·MISS는 입력 타이밍 표본에서 제외한다.
오차 단위는 원곡 1배속 시간축의 ms다. 재생 속도를 변경해도 저장된 입력 시각과 오차 단위를 재조정하지 않는다.
결과 화면과 기록 목록에도 적용한 전체·채보별 보정값을 표시한다.

단위 테스트로 설정 재실행 유지·채보별 분리·초기화·잘못된 값 거부, 원본/오디오 보존,
음수 입력 시각을 포함한 보정 리플레이의 점수 재현, 오차 표본 제외와 평균을 확인한다.
실제 Ebitengine 데모에 40/-15 ms를 적용해 14 KOOL·14,000점을 확인하고 화면을 캡처했다.
30 ms 늦은 입력을 2배속 재생한 캡처에서도 Last/Mean +30 ms와 저장된 +25 ms 보정을 확인했다.
실제 Wails 화면에서 전체 값 35 ms 입력·저장·0 ms 초기화와 `data/settings.json` 반영을 확인했다.

Wails의 실제 화면에서 곡·채보 선택, Auto 완주 후 결과 표시, 리플레이 보기, 재시작, 곡 선택 복귀와 기록 목록을 확인했다.
osu!mania 데모의 Auto·리플레이·재시작 결과는 14 KOOL, 14,000점, 정확도 100%로 일치했다.
일반 플레이 완주 기록은 Auto 최고 점수와 분리된다. 미완주 저장과 미완주 리플레이 종료도 실행 파일로 확인했다.
단위 테스트는 결과·리플레이 저장과 점수 재현, 손상된 파일 거부, 채보별 기록 분리와 모드·완주 상태 보존을 확인한다.
지원 범위와 게임 조작은 [채보 안내](charts.md), OS 입력 조건은 [입력 안내](../dev/input.md)를 참고한다.

## 적용 레벨과 목록 위치

정렬·필터 창의 **배속 적용 레벨로 정렬·필터**는 기본으로 켜져 있다. 현재 Time Rate의 표시 레벨로 레벨 순서·레벨 구분선·곡 안의 채보 순서·레벨 필터·레벨 분포를 계산한다. 끄면 정렬과 필터는 원곡 1배속 레벨을 쓴다. 배속 변경이나 선택한 채보의 정확한 레벨 계산이 끝나면 현재 선택을 유지하며 목록을 다시 정렬한다. 미계산 레벨은 양방향 정렬 모두 뒤에 둔다. 두 계산 프리셋 사이의 표시 추정치는 정렬에서도 같은 값을 쓴다. 키 배치만 바꾸고 표시 레벨이 바뀌지 않는 모드는 순서를 바꾸지 않는다.

목록 위의 **선택 N / 전체 개수 · 표시 A–B**와 작은 범위 막대는 검색·필터에 맞는 전체 채보 중 선택 위치와 현재 화면에 보이는 범위를 나타낸다. 휠·키보드·목록 크기 변경 때 갱신한다. 곡 묶음의 접힌 한 줄은 그 곡에 속한 채보 범위를 나타낸다.


자켓과 Info는 별도 행으로 배치한다. 자켓은 원본 비율을 유지하고 최대 높이 180px 안에 표시하며 제목·난이도·레벨은 그 아래에 둔다. 웹 OJN 자켓 미리보기는 내장 이미지의 바이트 구간만 반환한다. 게임 로더의 원본 파일 요청은 계속 전체 파일을 받아 저장된 오프셋으로 읽는다. 결과 저장 후 목록 점수·성과도 즉시 다시 계산한다.
