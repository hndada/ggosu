# 곡 검색·다운로드·설치

곡 선택창의 **곡 받기 [F9]**를 누른다. 제목·아티스트·제작자로 검색하고 키 수를 고른 뒤
**다운로드·설치**를 누르면 내려받기 → 압축 해제 → 채보·음원 확인 → 설치를 진행한다.
완료하면 곡 목록을 다시 읽고 설치된 채보를 선택한다. 일반 플레이 중이면 목록 반영은 플레이 종료 뒤에 한다.
압축 파일을 따로 옮기거나 곡 폴더를 직접 등록할 필요가 없다.

## 검색원

- **osu!mania**: 기존 아카이브 수집 코드와 같은 osu.direct API를 사용한다. 로그인 없이 mania 모드의 세트를 검색한다.
  한 페이지는 원격 결과 20개이며 키 수 필터는 포함된 mania 난이도 기준이다. 원격 페이지에서 조건에 맞는 곡이 없으면 다음 페이지를 확인한다.
- **채보 아카이브**: `cmd/archive` 서버의 `/api/packs` 검색과 `/d/<source>/<id>` 파일을 사용한다.
  osu·BMS·StepMania/Etterna 팩을 검색할 수 있다. 서버에 보관되지 않은 파일과 지원하지 않는 압축 형식은 이유를 표시하고 설치 버튼을 끈다.

아카이브의 기본 주소는 `http://127.0.0.1:8091`이다. 곡 받기 창에서 주소를 바꾸고 저장하면 다음 실행에도 유지된다.
멀티 서버의 기본 포트 8090과 구분한다.

```powershell
build/bin/archive.exe serve -root D:/archive -addr 127.0.0.1:8091
```

아카이브의 색인·파일 수집 방법은 [아카이브 안내](archive.md)를 참고한다.
osu!mania 기본 검색원은 아카이브 서버를 별도로 실행하지 않아도 사용할 수 있다.

## 설치 위치와 범위

데스크톱은 실행 파일 옆 `data/downloads/<source>-<id>/`에 설치하고 해당 루트를 곡 폴더 설정에 자동 등록한다.
브라우저는 **직접 접속한 localhost 웹 서버**의 `songs/downloads/`에 설치한다.
웹 서버에 원격으로 접속한 사용자는 검색만 할 수 있다. 원격 사용자나 공개 프록시를 통해 서버의 곡 폴더를 변경하지 않는다.
웹의 아카이브 주소는 서버 실행 옵션 `-archive-server`로 설정한다.

```powershell
build/bin/web.exe -songs songs -archive-server http://127.0.0.1:8091
```

현재 설치 형식은 **ZIP·OSZ·SMZIP**이다. 그 안의 osu!mania·O2Jam·BMS·StepMania·GGC 채보와 음원·이미지를 함께 옮긴다.
RAR·7z·LZH와 원곡 없는 BMS 차분은 자동 설치하지 않는다. 기존 아카이브의 7z 기반 색인과 앱의 설치 지원 범위는 별개다.
최대 다운로드 1 GiB, 압축 해제 2 GiB, 파일 20,000개로 제한한다. 실행 파일과 명령 파일은 설치하지 않는다.

## 완료·취소·실패

- 다운로드 바이트와 압축 해제 파일 수를 표시하며 설치 중 취소할 수 있다.
- 임시 폴더에서 검증한 뒤 최종 폴더로 한 번에 반영한다. 중간 파일은 곡 목록에 나타나지 않는다.
- 상위 폴더·절대 경로·드라이브·링크·중복 파일 경로를 거부한다. 원본 파일명과 디렉터리 배치는 유지한다.
- 일반적으로 필요한 음원이 없거나 플레이 가능한 채보가 없는 묶음은 설치하지 않는다.
  osu 기본 히트사운드는 기존 게임의 폴백을 사용하므로 묶음 안에 없어도 된다.
- 취소나 실패 시 임시 파일을 정리하고 기존 곡을 유지한다. 이미 설치된 묶음은 다시 내려받거나 덮어쓰지 않는다.
- 같은 설치 위치에 사용자 파일이 있으면 보존하고 오류를 표시한다. 자동 업데이트·기존 파일 교체는 제공하지 않는다.

실제 mania 다운로드 검사에서 발견한 `SampleSet: None`은 공식 osu! 디코더처럼 Normal 기본값으로 읽는다.
참고: [osu! LegacyBeatmapDecoder](https://github.com/ppy/osu/blob/master/osu.Game/Beatmaps/Formats/LegacyBeatmapDecoder.cs).

## 구현

- `internal/download`: 카탈로그 검색·진행 상태·다운로드·안전한 압축 해제·설치 검증.
- `internal/menu/download.go`: 설정 저장·곡 폴더 등록·Wails 바인딩·종료 시 취소.
- `scenes/songselect/download.js`: 검색·페이지·설치 진행·오류·취소 UI.
- `internal/server/web/download.go`: 웹 검색과 localhost 설치 API.

공개 검색·다운로드 서버의 서비스 상태나 배포 정책에 따라 요청이 실패할 수 있으며, 그 이유는 창 안에 표시한다.
