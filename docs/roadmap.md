# 개발 계획

미완료 항목은 위에서 아래 순서로 구현한다. 메타데이터·검색·필터·정렬·랜덤 선택은 완료했다.
다음 작업은 **수동 컬렉션**, 이후 **검색 조건 기반 자동 컬렉션**이다.
설정·곡 선택·결과 화면은 Wails, 게임 플레이와 실시간 피드백은 Ebitengine에서 처리한다.
완료 항목은 아래에 모았으며, CLI·단축키로만 제공되는 범위를 별도로 표시한다.

### 1. 곡 탐색·관리

- [ ] 수동 컬렉션 (생성·이름 변경·삭제, 채보 추가·제거, 저장·재실행 유지)
- [ ] 조건 기반 자동 컬렉션 (검색·필터 조건 저장, 목록 갱신 시 조건 재평가)
- [x] 곡 받기: 원격 검색·다운로드·설치·검증·곡 폴더 등록·목록 갱신 (ZIP·OSZ·SMZIP)

수동 컬렉션은 원하는 채보를 직접 모으고, 자동 컬렉션은 구현된 검색·필터 조건으로 목록을 구성한다.

### 2. 연습·결과 분석

- [x] 연습 구간 지정 (F1 노트 밀도 그래프에서 드래그, 채보별 기억, 구간 자동 반복)
- [ ] 판정 범위 조절
- [ ] 게이지 조절

- [ ] 구간별 타이밍 편향

### 3. 배치 변형·기록 비교

- [ ] 라이벌·고스트 비교

### 4. 스킨·미디어·오디오 고급 설정

- [ ] 스킨
- [ ] 곡 선택·설정 화면 테마 색 변경 (theme.css의 `:root` 변수를 사용자가 바꾸고 저장)
- [ ] 키음 샘플 교체 설정
- [ ] 영상 재생·표시 설정
- [ ] 출력 장치 선택·지연 보정

### 5. 패턴 라이브러리

- [ ] 현존 채보에서 단위패턴 추출·저장
- [ ] 패턴 검색·분류·조회

### 6. 난이도 평가

- [ ] 난이도 모델 계수 보정·실제 플레이 데이터 검증
- [ ] 검증한 난이도 지표를 곡 선택창에 연결

### 7. 채보 편집

- [x] Edit 기본 화면·노트/타이밍 편집·파형·구간 재생·`.ggc` 사본 저장
- [x] 음원 BPM·시작 위치 자동 추정·구간별 후보·메트로놈 확인·제작 환경 로컬 보정·실시간 Tap 입력
- [ ] 게임 엔진 판정이 연결된 편집 채보 테스트·원본 포맷 내보내기·동시 채보 비교

곡을 고른 뒤 **Edit**를 누르면 편집한다. 저장은 원본 곡 폴더에 새 `.ggc` 사본을 만들며,
Test는 현재 위치부터 편집 내용의 오디오·노트·레인 키를 확인하는 미리보기다. [Edit 안내](guide/edit.md).

### 8. 멀티플레이·온라인

- [x] 멀티플레이 서버 (방·준비·시작·진행·결과 공유·이탈 처리, 프로토콜 테스트 화면)
- [x] 네이티브 멀티 연결 (CLI 방 생성·참가, QPC 시작 예약, 같은 시각 점수 이력 비교·상대 표시)
- [x] Wails 멀티 대기실 UI (연결 유지·채보 보유자 Go·곡 제안·다음 곡·포기 후 대기실)
- [x] 방 채팅 (서버 메시지·최근 이력, 웹/네이티브 오른쪽 접이식 패널·초안·미확인 개수)
- [x] 비밀번호 방 (서버 검증·잠금 표시·데스크톱 입장창·CLI·게임 연결 티켓 유지)
- [ ] 순위
- [x] 일반 플레이 점수 자동 제출·서버 리플레이 검증·영구 저장·중복 방지·실패 재시도 (계정 인증·온라인 순위는 별도)

- [x] 같은 배치 조건의 이전 최고 기록 대비 점수·정확도·콤보·판정별 변화
